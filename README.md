Personal Portfolio Website
A sleek, responsive, and professional portfolio website designed to showcase my skills, projects, and professional journey. This site serves as a central hub for my digital presence and contact information.

🌐 Live Demo
You can view the live version of this portfolio here:

https://siddhartha-12.vercel.app

🚀 Features
Responsive Design: Fully optimized for all screen sizes, including desktops, tablets, and mobile devices.

About Me: A professional overview of my background, interests, and career goals.

Skills Showcase: A dedicated section highlighting my technical expertise in Web Technologies and Programming.

Project Gallery: Visual display of my latest work with links to source code and descriptions.

Contact Integration: Easy-to-use links for social media, GitHub, and email communication.

🛠️ Tech Stack
HTML5: Structured content for a semantic and accessible web experience.

CSS3: Custom styling and layout using modern techniques (Flexbox/Grid).

Images: Optimized assets for fast loading and visual appeal.

Deployment: Hosted and automatically deployed via Vercel.

To run this project locally on your machine:
